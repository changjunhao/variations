# 月历 Zine 明信片 Monthly Zine Postcard

**上半是证据，下半是一页缩小的月历摄影页。**

这不是一张"照片下面放一幅水彩插画"的普通明信片：上方完整保留原照片，下半严格按量化空间关系排成一页横向月历摄影页——左上自由边缘水彩块、右侧暖白书签栏、手写句与三段页脚。照片与月历页同等重要。

## 画幅（固定 3:4）

画布固定 3:4 竖版（1200×1600），暖象牙白纸张、极轻纸纹，不随源图朝向改变，不旋转画布。
源图一律 `contain` 完整容纳：禁止裁切、cover、拉伸、重绘、替换，或去除原图自带的边框 / EXIF / 品牌字。

## 决策优先级（冲突时按此顺序）

1. 照片保真——原图内容、色彩、比例、摄影质感原样保留，不水彩化
2. 固定版式——下半"水彩块—侧栏—手写句—留白—页脚"的空间节奏高于一切风格细节
3. 文字逐字锁定——所有上画文字来自用户输入或本文默认值，逐字照抄，不改写不翻译不补造
4. 文学与歌曲只署真名——无法确定真实出处时，一律走原创旁白 / 歌曲区留白的兜底，禁止伪造书名、作者、名言、歌手或歌名

## 第一步：分析源图并路由上半区

先确定原图宽高比 `r = width / height`：优先采用服务端测定注入的像素尺寸；未注入时才目测源图。

| 源图条件 | 上半展示模式 | 规则 |
|---|---|---|
| `r ≥ 1.70` 超宽横图 | 横向摄影条 | 容器高 29%–32% 卡高，居中，最大宽约卡面 90% |
| `1.15 ≤ r < 1.70` 常规横图 | 标准横向照片区 | 容器高 31%–34%，居中，最大宽 88%–92% |
| `0.85 ≤ r < 1.15` 方图 | 居中照片卡 | 容器高 35%–38%，按高度完整容纳，不拉满宽度 |
| `r < 0.85` 竖图（含极窄长图） | 竖向照片票据 | 容器高 40%–42%，按高度完整容纳；两侧留白必须显得像刻意的纸张留边 |

补充：容器内的剩余纸边是设计留白，不是待填充区域。输入若已含相机框、EXIF、装饰框，按"完整摄影成品"整体保留。

同时从原图读取：主体、光线、空间感、情绪、主色——供下半水彩与文字配色使用。

## 第二步：锁定下半月历页版式（全部量化）

下半是一页**缩小的横向月历摄影页**，不是第二张海报、不是大竖幅插画：

- 下半页高度：常规/超宽横图 66%–69%；方图 62%–65%；竖图 58%–60%。更矮的下半页只允许收紧垂直间距（至多 15%），不得改变左右比例、字级与页脚关系。
- **左上水彩视觉块**：占下半页宽 66%–70%、高 50%–54%，位于左上，四周留纸张边距，绝不触及页脚。
- **右侧书签栏**：占下半页宽 24%–28%，从顶部延伸到歌曲区；完整暖白背景，无边框、无分割线、无插画。
- **手写句**：仅在水彩块下方左侧，基线约在下半页高 58%–62%，不跨入右栏。
- **留白带**：页脚线前的纯留白最多占下半页高 8%–12%。
- **页脚**：细横线位于下半页高约 86%–88%，线下三段文字。

## 第三步：左上水彩视觉块

从原图提取**一个完整视觉关系**（主体 + 空间 + 光线），不是最容易抠出的物件：水彩 + 克制墨线，自由有机飞白边缘，保留原图轮廓与色彩关系，横向景色。视觉块必须是**手绘水彩质感**——可见颜料晕染、干刷飞白与墨线轮廓，绝不是真实照片，也不是带水彩边缘的照片裁切。

- 只提取摄影主体与场景关系；禁止把 EXIF、品牌字、界面框、相机框复制进水彩。
- 不得拆成多个小样本、拼贴块或多组主体；不得成为占满下半页的大插画。

## 第四步：右侧书签栏（三组，沿同一垂直中轴居中）

1. **月份锚点（栏高 0%–18%）**：两位月份数字是唯一最大字号，英文月份紧随其下居中。月份取用户提供的值；未提供时按源图的季节与光线特征推断一个贴切月份，不得编造拍摄日期。
2. **文学竖排（栏高 32%–62%）**：右列竖排短标题，左列竖排短句，两列间距约 0.35–0.5em。用户提供文学文字时逐字使用；未提供时生成**原创旁白**（不署任何书名、作者），标题为 2–4 字原创短语。
3. **音乐落款（栏高 82%–90%）**：一枚极小耳机图标居中置于歌曲行正上方，图标与文字绝不并排。仅当用户提供歌曲时才渲染歌曲文字；未提供时此区只留耳机图标或整体安静留白，禁止填任何虚构歌手歌名。

文学组与音乐组之间保留右栏最大一段刻意留白。不放歌词、Logo、二维码、播放按钮。

## 第五步：文字清单与渲染安全（逐项逐字锁定）

整图文字严格只有以下 9 项（歌曲行可无，省略时恰为 8 项），各出现 1 次，全部按精确字符串渲染，不改写、不翻译、不换标点：

1. 月份数字：恰好 2 位阿拉伯数字（如 `08`）
2. 英文月份：1 个英文单词（如 `August`）
3. 文学短标题（右列竖排）：用户文本，或 2–4 字原创短语
4. 文学短句（左列竖排）：≤10 个汉字的一行竖排短句；用户文本超长时截取前 10 字
5. 歌曲行（横排，可无）：`歌手《歌名》` 整行 ≤12 字；未提供则不渲染
6. 手写句（水彩下方，轻盈手写体）：英文 ≤6 个单词；默认 `Run to mountains and seas.`
7. 页脚左：署名 ≤12 字符；默认 `VARIATIONS`
8. 页脚中：日期（如 `2026.08.10`）；未提供则该位置完全空白，不补造、不画任何符号、引号或占位符
9. 页脚右：收束语英文 ≤6 个单词；默认 `Free to sway and thrive.`

竖排中文必须自上而下、清晰可辨；除上述各项外不出现任何编号、标签、说明文字。

## 第六步：色彩与字级体系

- 从原图情绪主色提取**一种**低饱和深色，用于月份、文学、耳机、手写句、细线与页脚，确保在暖白纸上可读；全图只用这一种文字色。
- 以手写句与文学短句为基准 `1.0`：文学短标题 1.5x（1.45–1.55，优雅中等字重衬线，不用粗体）；英文月份 1.5x；页脚 0.8–0.9x；歌曲 0.7–0.75x；月份数字 4.0–4.5x，是唯一大于标题的字级。右栏除月份数字外没有任何文字可大于文学短标题。

## 预防性约束（没有第二次机会，提示词里提前封死）

- 照片被水彩化/重绘 → 必写"上方是真实摄影照片，锐利边缘，不水彩化不重绘"
- 下半画成第二张大海报/大竖幅插画 → 必写"缩小的横向月历摄影页，不是第二张海报"
- 水彩触到页脚或占满下半页 → 必写"占下半页宽约 68%、高约 52%，绝不触及页脚"
- 视觉块变成照片裁切 → 必写"整体重绘为手绘水彩插画，平涂透明色层与细墨线轮廓，下半页任何部分不得出现照片质感或摄影细节"
- 右栏被侵入或加边框 → 必写"右侧只是纸面上的文字栏，与卡面同一张暖象牙白纸，不画书签形状、丝带、吊牌、矩形框、色块、阴影、边框或竖线"
- 空日期出现占位符号 → 必写"日期未提供时该位置完全空白，不画任何符号、引号或占位符"
- 页脚错位（文字跑到线上方或横线不贯全宽） → 必写"细横线横贯下半页全宽，三段文字同排在线下，左/中/右对齐"
- 伪造书名/歌曲 → 未提供时只走原创旁白与留白兜底，骨架中不得出现任何编造出处
- 文字乱码与超量 → 逐字列全第五步全部文字项 + "全图文字只有上述各项，逐字照抄，不增不改"
- 竖排中文横排化 → 必写"竖排中文自上而下"
- 超长用户文本 → 按第五步字数上限截取，绝不缩字挤排

## 质量门（交付前逐项过，单次生成无重试）

- 3:4 竖版画布，暖象牙白纸，无外部卡片或样机？
- 上半原照完整 contain，无裁切拉伸，摄影质感未变？
- 下半是缩小横向月历页：水彩块在左上、不触页脚、只有一枚，且整体为手绘水彩、无任何照片质感？
- 右栏 24%–28% 宽、与卡面同纸色、无边框无竖线无纸条阴影、三组元素沿中轴？
- 只有月份数字大于文学短标题？耳机图标在歌曲行上方？
- 手写句在水彩下方左侧，未跨入右栏？
- 页脚一条细线 + 三段文字，独立于水彩？
- 文字恰好为第五步清单各项、各一次、逐字无误、无乱码、无额外文字？
