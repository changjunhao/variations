# 静影双联 Quiet Diptych

**照片是此刻，插画是回声，留白是呼吸。**

这不是"照片加插画"的拼贴，而是一本经过完整艺术指导的独立出版物封面：上半是可信的摄影此刻，下半是同一场景被轻轻放在纸上的手绘回声，两半等高、明确区分，又在色彩与叙事上自然衔接。

## 画幅（固定 3:4）

- 画布固定 3:4 竖版（1200×1600），不随源图朝向改变，不旋转画布，不切换横版。
- 画面水平分为上下两个等高区域，各占 50%；交界为一条干净的水平直边：不画分隔线、不留缝隙、不加白边、圆角或投影。
- 每张源照片独立生成一张海报；多张源照片时逐张独立生成，禁止把多张照片拼贴或合并进同一张。

## 决策优先级（冲突时按此顺序）

1. 照片保真——上半主体身份、构图、摄影质感原样保留
2. 固定双联版式——50/50 等高、两半各自满幅
3. 插画极小——下半涂绘覆盖仅 10%–20%，留白是主角
4. 色彩忠于源图——≤4 色且全部提取自上半照片
5. 文字克制——宁可省略，不可强加

## 第一步：分析源图

读原图，逐项确定：

- **主体与叙事（一句）**：最具辨识度的主体、基本轮廓、关键动作、重要物体、人与环境的核心关系；移除无关细节，只保留能让人立即认出原场景的视觉信息。
- **环境暗示元素（至多两项）**：如"一抹托着月亮的云影""两丛树影与一盏石灯笼"，仅用于下半四周的少量线条或小色块。
- **≤4 色**：直接从照片提取主导色并压缩：通常为主色 + 辅色 + 深色 + 纸的暖米白；记为中文色彩词。
- **文字**：标题（英文 2–4 词宽字距大写，或中文 ≤8 字）、地点（≤12 字）、年份（4 位数字）。用户提供了就逐字采用；未提供则从照片推断；无法自然推断则该行的值留空。

## 第二步：上半——原始摄影（50% 满幅）

- 原样保留：主要构图、主体身份、五官、身体比例、姿势、表情、服装、物体、空间关系。
- 保留真实摄影质感：自然光线、阴影、氛围、原始色彩基调；只做细微、克制的编辑级调色，接近高端杂志摄影或当代艺术书籍。
- 横带适配（上半为 3:2 横带）：为适配可自然扩展天空、地面、墙壁或周围环境，但必须无缝、真实；或做最小限度的中心加权裁切；不得拉伸、扭曲、重塑、替换主体或改变人物身份。
- 无缝扩边：扩展的天空、地面、墙壁必须延续原有云纹、材质与光影渐变，禁止涂出纯色带、水平接缝或突兀空白区。
- 等比直铺：源图比例已与上半横带（≈3:2）相符时，原构图直接满幅铺放，不重新构图、不额外加天空头顶或前景；仅比例不符时才做无缝扩边或最小裁切。
- 满幅：照片铺满上半区域四条边，不加相框、白边、圆角、投影或样机。
- 禁止：过度磨皮、夸张滤镜、人为风格化、水彩化、插画化、边缘晕染。

## 第三步：下半——极简手绘纸质插画（50%）

- **纸张**：粗糙白纸、温暖米白纸或浅色天然纸张，可见纸纹与极轻纤维感；纸张铺满下半区域四条边。
- **重绎**：把第一步确定的主体与叙事重新诠释为高度简化的手绘插画，只保留能让人立即认出原场景的视觉信息。
- **手法**：精细但略带瑕疵的手绘线条 + 少量丙烯感平面色块 + 可见笔触 + 轻微不规则边缘；保留真实手作感。
- **尺度**：主体小巧、居中且构图讲究，涂绘覆盖仅占下半部分约 10%–20%，视觉包络不超过下半宽 55%、高 45%；四周留出 ≥80% 安静的负空间；包络内元素之间保留纸白呼吸缝隙，禁止堆叠完整场景全景（山脉、建筑群）或以实色块填满包络。
- **环境**：只用第一步的环境暗示元素以少量线条或小色块暗示，不铺满画面。
- **禁止**：彩色铅笔、蜡笔、晕染水彩、纯线稿、复杂写实插图、浓重油画、过度平滑的数字插画、3D 渲染、光泽纹理、商业卡通、可爱商业角色、电商广告、通用海报模板。

## 第四步：色彩与衔接

- 全图画板压缩至不超过 4 种颜色（含纸的暖米白），全部直接从上半照片提取，禁止源图没有的色相。
- 下半以大胆但受控的平面色块呼应上半主导色；避免过多渐变和杂色。
- 上下两半既有明确区分，又在色彩和叙事上自然衔接，像同一位艺术指导的完整作品。

## 第五步：排版（文字渲染安全）

- 位置：下半底部居中，自上而下至多三行：标题 / 地点 / 年份；年份下可加一条极短横线收束。
- 各行字数硬限：标题英文 ≤4 词或中文 ≤8 字；地点 ≤12 字；年份 4 位数字。
- 逐字照抄第一步确定的文字；某行的值留空则整行省略，禁止编造占位符、Unknown、Undated。
- 字体：极小衬线、宽字距（字距 ≥ 半个字宽）、低对比灰褐或源图深色，禁止纯黑；标题高度约画布高的 2%–2.5%，地点与年份比标题再小一号；与留白和小插图自然互动；若无法自然融入，则省略全部文字。
- 禁止：密集排版、描述性段落、徽章、logo、水印、任何其他文字。

## 第六步：提示词骨架

替换全部方括号槽位，按"双联声明 → 上半照片契约 → 下半纸与插画 → 色彩 → 文字 → 禁止项"顺序组装：


槽位填写约定：

- [主体与叙事] 用一句中文（如"持弓回望的巫女、鸟居、石灯笼与崖上夜神社"）
- [环境暗示元素] 用中文、至多两项（如"一抹托满月的云影、几枝樱影"）
- [色1]–[色4] 用中文色彩词（如"夜蓝""朱红""暖米白""墨黑"）
- [文字行] 逐行写为 `标题 "MOONLIT SHRINE"、地点 "月下神社"、年份 "2024"`；全部留空时写"无文字"

## 预防性约束（没有第二次机会，提示词里提前封死）

- 照片被风格化/水彩化 → 必写"上半是真实照片，保留摄影质感，禁止水彩化、插画化、夸张滤镜"
- 照片被拉伸或换主体 → 必写"禁止拉伸、扭曲、重塑、替换主体、改变人物身份"
- 扩边天空纯色带/接缝 → 必写"源图比例与横带相符时原构图直接满幅铺放；扩展的天空延续原有云纹与光影渐变，禁止纯色带与水平接缝"
- 插画包络被实色填满 → 必写"包络内保留纸白呼吸缝隙，禁止堆叠场景全景或以实色块填满"
- 插画过大、留白被吃 → 必写"插画涂绘覆盖仅占下半 10%–20%，四周 ≥80% 安静负空间"
- 纸感缺失或被铺满 → 必写"暖米白粗糙纸张铺满下半，纸纹隐约可见，环境暗示不铺满画面"
- 质感漂移到水彩/蜡笔 → 必写"丙烯感平面色块与精细手绘线条，禁止彩色铅笔、蜡笔、晕染水彩"
- 色彩漂移 → 逐名列出 ≤4 色 + "禁止源图没有的色相"
- 文字乱码或编造 → 逐行列出文字 + "值留空则整行省略，此后不出现任何其他文字"
- 文字过大过黑 → 必写"标题高度约画布高的 2%–2.5%、宽字距、低对比灰褐，地点与年份再小一号"

## 隐私

不在标题、地点、年份或任何画面文字中暴露全名、个人邮箱、电话号码、证件号、住宅地址、凭据或精确坐标等个人信息；地点只写到城市或景点粒度。

## 质量门（交付前逐项过）

- 3:4 竖版、上下等高 50%、两半各自满幅、交界干净直边？
- 上半真实摄影质感，主体身份与构图未变，无风格化？
- 下半暖米白粗纸，插画极小居中，涂绘覆盖 10%–20%，留白 ≥80%？
- 手绘线条 + 丙烯平面色块 + 可见笔触，无水彩/蜡笔/3D/光泽质感？
- ≤4 色且全部源自上半照片？
- 文字 ≤3 行、逐字准确、无乱码、无编造占位？
- 整体安静、诗意，像独立艺术书封而非商业广告？
