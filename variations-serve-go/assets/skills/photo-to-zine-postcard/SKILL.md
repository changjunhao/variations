# 摄影 Zine 明信片 Photo Zine Postcard

**照片是证据，插画是注释，留白是态度。**

这不是一张用水彩装饰的旅行明信片，而是一页能当明信片用的独立摄影 Zine 内页：上方原样嵌入原照片作为证据，中段保持沉默的大面积留白，下方是从原图提取的一枚手绘视觉注释、三个颜料试色点和一组档案文字。

## 画幅（固定 2:3）

画布固定 2:3 竖版明信片（1024×1536），不随源图朝向改变，不旋转画布，不切换横版。
横版/方图源图：照片保持原始比例嵌入框内，框内余位以纸白消化，禁止裁切或拉伸填满。

## 决策优先级（冲突时按此顺序）

1. 照片保真——原图内容、色彩、比例、摄影质感原样保留，不重绘、不扩图、不换图
2. 固定版式——量化布局不随意改动，大面积连续留白必须保留
3. 色彩忠于源图——三个色系从原图提取，不擅自偏移冷暖
4. 克制的注释——墨线+薄水彩的观察笔记，不是第二幅完整绘画
5. 恰好三枚试色点
6. 文字恰好五项、各出现一次

## 第一步：分析源图

读原图，逐项确定：

- **主母题（一个）**：选"视觉吸引力 + 来源代表性"组合最强的，而不是最容易分离的。优先：醒目的色彩形态（碧绿水面、被照亮的山脊）> 清晰轮廓（岸线、山形、树丛、植物簇）> 建筑片段、窗与藤蔓、倒影、云与影。源图中存在主导色彩特征时，主母题必须来自它（绿松石湖 → 水面与岸线，而不是米色碎石）；不选灰暗低对比的碎片，也不因"容易分离"就退而求其次。
- **辅助碎片（可选，至多一个）**：同一叙事，体积不超过主母题的 25%。
- **三个色系**：chromatic = 最有代表性的着色特征；structural = 最深的结构暗色；quiet = 浅色中性/天空/矿物色。
- **标题**：英文 2–4 个词。
- **LOCATION / DATE**：用户提供了才填写，否则留空；禁止编造 Unknown / Undated。

## 第二步：锁定版式（全部量化，不得擅改）

**纸张**：暖象牙白约 #F5F1E8，极轻微无涂布纸纹，纸张延伸满四条画布边缘；不画卡片轮廓、圆角、外部背景、阴影样机，不加泛黄做旧滤镜。

**照片区**：占画面上部 42%–46%、宽 86%–90%，水平居中；保持原图原始比例；只加极细灰色边线与均匀窄纸缝；禁止宝丽来、厚卡纸衬、胶带、剪贴簿角贴、投影、说明条。照片本身必须保持真实摄影质感与锐利边缘：不水彩化、不插画化、边缘不晕染——水彩/墨线语言只用于下半部的视觉注释。

**留白**：照片与下方内容之间保留 14%–18% 画面高度的连续象牙白，绝对不填充任何装饰——这份安静是 Zine 的第一手法，不是待填满的空地。

**下方编集区**：左下 = 唯一一组档案文字；右下或偏中右 = 主视觉注释；试色点 = 档案文字下方一行。注释占卡片宽 45%–56%、高 18%–26%，必须从属于照片，不得成为第二张海报。

## 第三步：绘制视觉注释（默认墨线+薄水彩）

做的是"选择性的实地观察笔记"，不是完成的风景画：

- 细冷灰墨线控制结构，叠加透明、克制、偏干的水彩薄涂
- 轮廓断续不完整，边缘自然消失在纸面，内部保留大量纸白
- 保持原图轮廓与可辨识身份，饱和度略降，色彩关系忠于源图
- 直接画在纸上：无矩形底色、无包围边框、无分隔线

仅当简化即失去身份时改用原图裁切兜底（轻软化、与纸面融合）：人脸、手部、文字招牌、精密机械、复杂透视、密集重复细节。

禁止：厚重湿水彩、浑浊积水、粗黑描边、油亮数字绘画、照片级重绘、动漫/绘本/概念艺术风、满版插画矩形、擅自高饱和、第二份完整的源照片。

## 第四步：色彩保真

三个色系原样用于注释插画；为无涂布印刷感可略降饱和，但禁止色相漂移：蓝水→绿松石、绿植→青绿、暖石→橙、中性白→黄（除非源图本就含该色相）。不加彩虹色、时髦互补色或额外强调色。

## 第五步：三枚试色点

一行三个颜料试色点，顺序 chromatic → structural → quiet：

- 每枚约占卡片宽 4%–5%，大小一致，间距均匀
- 圆形/软方块/小笔触点，边缘带手绘颜料的轻微不规则，哑光，无标签
- 禁止 UI 色块、圆角贴片、渐变、长条色卡、第二行、外围边框（浅色点为可辨识可加一条极细边线）

## 第六步：五项文字（文字渲染安全）

安静的古典书衬线体系。整图文字严格只有 5 项、各出现 1 次：

1. 标题（英文 2–4 词，逐字照抄第一步确定的标题）
2. 斜体 `Postcard`
3. `LOCATION` + 短横线（值留空则只留横线）
4. `DATE` + 短横线
5. `No. 0XX`（三位数字编号）

全部集中在左下档案块；不在其他位置重复任何文字；不加描述、坐标、关键词、署名、徽章、logo。整图唯一允许的直线：照片极细边线 + LOCATION/DATE 后各一条短横线——不画任何其他竖线、横线、线框或矩形边框。

## 第七步：提示词骨架

替换全部方括号槽位，按"Zine 声明 → 画布与照片边界 → 留白 → 母题与注释 → 三色系 → 试色点 → 文字 → 禁止项"顺序组装：

```text
生成一张 2:3 竖版的独立摄影 Zine 内页，同时可以作为明信片正面。它不是旅行纪念明信片，不是 Polaroid，不是剪贴簿，也不是"照片下面放一幅水彩画"。整张图是平面的单张成品，不要展示桌面、投影、圆角卡片或样机。

上方嵌入用户提供的真实照片，占画面高度约 44%、宽度约 88%，居中。上方必须是真实摄影照片：锐利边缘、真实摄影纹理与细节，不水彩化、不插画化、边缘不晕染；水彩与墨线语言只用于下半部注释。保持原照片内容、色彩、比例和摄影质感不变，不重绘、不扩图、不换图、不美化。只加极细灰色边线与均匀窄纸边；禁止厚相框、胶带和阴影。

照片下方保留约 16% 画面高度的连续象牙白留白，绝对不要填充装饰。

下半部左侧是唯一一组极简档案文字；右侧是从原照片提取的"[主母题]"视觉注释。视觉注释不是完整风景画：使用细冷灰墨线控制结构，叠加透明、克制、偏干的水彩薄涂；轮廓断续，边缘自然消失在纸面，内部保留大量纸白，像独立摄影杂志中的手绘观察笔记。保持原照片真实轮廓和色彩关系，整体轻、薄、安静、低饱和。下半部不画矩形边框，不画包围插画或文字的线框，不画左右分隔竖线或上下分隔横线；唯一允许的直线只有照片极细边线以及 LOCATION、DATE 后各一条短横线。

颜色只允许围绕原照片提取的三个色系：[chromatic]、[structural]、[quiet]。不得自行增加互补色或改变冷暖关系。

左下方优先只出现一行三个小型颜料试色点，顺序为 [chromatic]、[structural]、[quiet]。大小一致、间距均匀、哑光、边缘略有手工颜料的不规则感；不要 UI 色块、长条色卡或第二行色点。

文字严格只有五项且各出现一次：标题"[标题]"、斜体"Postcard"、LOCATION 与空白短横线、DATE 与空白短横线、No. [编号]。第 5 项之后不再出现任何编号或文字。

纸张为中性暖象牙白，只有极轻微的无涂布纸纹。整体气质：independent photography zine、editorial archive、Swiss/Japanese book design、quiet collectible print、large negative space。
```

槽位填写约定：

- [主母题] 用中文描述母题轮廓（如"绿松石色湖面与远山倒影的岸线"）
- [chromatic]/[structural]/[quiet] 用中文色彩词（如"明亮的绿松石色"/"深青绿"/"浅矿物沙色"）
- [标题] 逐字照抄英文标题本体，不带方括号或任何符号；[编号] 用三位数字
- 横版源图追加一句："原照片为横版，保持其原始比例放入框内，框内上下以纸白延伸适配，不裁切。"

## 第八步：背面（仅当明确要求时）

默认只交付正面。仅当用户明确要求背面时，以同一 2:3、同一纸色与细线语言生成一张：

- 细外边框；略偏中心的右侧竖分割线；右上邮票框；右侧 3–4 条地址线；左侧大面积空白留言区
- 可选：左上小字 `POST CARD`、左下极小编号、一枚极淡的源图衍生水印
- 禁止大拼贴、色卡、样品块等一切挤占书写空间的内容

## 预防性约束（没有第二次机会，提示词里提前封死）

- 照片被重绘/宝丽来化 → 必写"保持原照片摄影质感，不重绘不扩图，只加极细灰色边线"
- 照片被水彩化/插画化 → 必写"上方是真实摄影照片，锐利边缘，不水彩化不插画化，边缘不晕染"
- 留白被装饰填满 → 必写"绝对不要填充装饰"
- 注释画成第二幅风景画 → 必写"不是完整风景画，内部保留大量纸白"
- 插画被装进矩形 → 必写"不画矩形边框、不画分隔线"
- 色彩漂移 → 写明三个色系名 + "不得改变冷暖关系"
- 试色点变 UI 色块 → 必写"颜料试色点，哑光，边缘略不规则"
- 文字重复与乱码 → 逐字列全五项文字 + "第 5 项之后不再出现任何编号或文字"

## 质量门（交付前逐项过）

- 2:3 竖版画布，纸张延伸满四边，无外部卡片或样机？
- 照片未被改动，细边线 + 窄纸缝？
- 上方是真实摄影照片（锐利、非水彩/插画化）？
- 中段留白连续，没有任何内容？
- 右下注释清晰可读，细墨线 + 薄水彩，无矩形边框？
- 试色点恰好三个、一行、颜色来自原图？
- 文字五项、各一次、集中在左下？
- 边缘锐利、低噪点、无模糊无浑浊水彩，可支撑后续 4× 超分辨率放大？
